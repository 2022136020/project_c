## 2. Rules (행동 규칙)

1. 지시한 것만 수행한다
2. 지시가 모호한 경우 질문 후 행동한다
3. 모든 응답은 한국어로 작성한다 (기본값)
4. 작업은 단계별로 수행한다
5. 구현 후 반드시 동작 확인을 수행한다

---

## 3. Skills

### skill: 발표 전 점검
1. 평가 루브릭 기준으로 제출 서류 목록을 확인한다
2. 가산점 항목별 충족 여부를 점검한다
3. 미완료 항목을 우선순위 순으로 보고한다
4. 발표 당일 최종 확인 사항을 출력한다

## 5-1. 추가 기법 — 단계별 개발 후 보고 방식

**내용 요약**:
- AI로 개발을 진행할 때 각 단계 완료 후 반드시 결과를 보고받는 방식을 적용
- 단계가 끝날 때마다 "무엇을 했는지, 어떻게 동작하는지"를 AI가 요약 보고하도록 지시
- 개발 내용을 이해하지 못한 채 넘어가는 것을 방지 → 발표·Q&A 즉답 가능

**적용 예시**:
- 기능 구현 후: "방금 만든 기능이 어떻게 동작하는지 비전공자도 이해할 수 있게 설명해줘"
- 코드 작성 후: "이 코드에서 핵심 로직만 3줄로 요약해줘"
- 오류 수정 후: "왜 오류가 났고 어떻게 고쳤는지 설명해줘"
