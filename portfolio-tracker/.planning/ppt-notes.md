### AI 워크플로우 슬라이드 (ADR 바로 앞 — 가산점 어필 페이지)

3가지 항목을 한 슬라이드에:
1. **서브 에이전트 활용** — `.claude/agents/feature-debugger.md`, 기능별 체크리스트 자동 점검
2. **사용자 명령어** — `.claude/commands/` 슬래시 명령어 (생성 예정)
3. **AI 활용 학습** — Claude로 기술 결정 탐색, LLM Wiki 문서 작성

슬라이드 제목: "개발 과정 — AI 워크플로우"  
발표자 멘트: 가산점 A(서브에이전트), B(명령어), C(LLM Wiki) 자연스럽게 언급

### ADR 슬라이드 (발표 거의 마지막)

각 ADR별로 **선택지 목록 + 최종 선택만** 표시. 선택 이유는 발표자가 말로 설명하므로 슬라이드에 넣지 않는다.

**ADR-0001 — 모바일 프레임워크**
- 선택지: React Native / 안드로이드 전용 / 아이폰 전용 / **Flutter ✓**

**ADR-0002 — 아키텍처 패턴**
- 선택지: 역할 구분 없이 한 파일 / MVC / 6~8레이어 / **4레이어 구조 ✓**

**ADR-0003 — 백엔드**
- 선택지: Supabase / 폰 내부 저장 / 직접 서버 / **Firebase ✓**
